# 🍽️ Restaurant Website

## About the Project
A restaurant website built using HTML, CSS, and JavaScript. It allows users to explore food items, search for dishes, filter the menu, and manage selected items.

## ✨ Features
- **Food Menu:** Browse available food items.
- **Category Filtering:** Filter dishes by food category.
- **Ingredient Filtering:** Find dishes based on their ingredients.
- **Search:** Search for specific food items.
- **Item Management:** Add items and increase or decrease their quantities.
- **Price Display:** View food prices.
- **User Authentication Interface:** Login and registration forms.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone the project.
2. Open the project on your computer.
3. Open `index.html` in your browser.
4. Explore the website and its features.
